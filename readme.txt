Fun Quiz

A simple and interactive General Knowledge Quiz built using Python. Test your knowledge with multiple-choice questions covering everyday facts, animals, geography, sports and more!

Features
- Welcomes the player by name.
- Contains 20 multiple-choice questions.
- Questions are arranged by difficulty: Easy, Easy-Medium, Medium and Hard.
- Four options for every question.
- Keeps track of the player's winnings.
- Displays the correct answer when the player answers incorrectly.
- Ends the game when an incorrect answer is given.

Technologies Used
- Python
- Time module

How to Play
1. Enter your name.
2. Type `yes` to begin the quiz or `exit` to quit.
3. Read each question and choose an option (`a`, `b`, `c`, or `d`).
4. Earn virtual prize money for every correct answer.
5. One incorrect answer ends the game!
